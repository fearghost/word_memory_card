## Working Convention: CI-Driven Automation
- **Skip Local Builds/Tests:** Do NOT attempt local Gradle builds or tests. Validation is performed via GitHub Actions.
- **CI-Driven Loop:** Work follows a continuous loop:
    1. Monitor GitHub Action status (`gh run list`).
    2. On failure, analyze error logs (`gh run view --log`).
    3. Apply code fixes based on log analysis.
    4. Push changes to trigger a new run.
    5. Repeat until the CI status is `success`.
## AI SDK Troubleshooting & Upgrade Procedure
- **404 Model Not Found Error:** If `gemini-1.5-flash-latest` returns a 404, use the standard `gemini-1.5-flash` name.
- **Dependency Check:** Ensure `com.google.ai.client.generativeai:generativeai` is at least `0.9.0`.
- **Error Parsing:** If `MissingFieldException` occurs during error handling, it's a known SDK-side issue with parsing Google's error JSON; focus on the actual `error.message` in logs.
