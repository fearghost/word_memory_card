## Working Convention: CI-Driven Automation
- **Skip Local Builds/Tests:** Do NOT attempt local Gradle builds or tests. Validation is performed via GitHub Actions.
- **CI-Driven Loop:** Work follows a continuous loop:
    1. Monitor GitHub Action status (`gh run list`).
    2. On failure, analyze error logs (`gh run view --log`).
    3. Apply code fixes based on log analysis.
    4. Push changes to trigger a new run.
    5. Repeat until the CI status is `success`.
- **Safety:** If the same error persists after 3 attempts or appears to be a non-code/environment issue, stop and report to the user.
